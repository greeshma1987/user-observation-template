User Observation Template 

This project designs a UX Research Observation Template grounded in the AEIOU(Activities, Environments, Interactions, Objects, Users) and POEMS(People, Objects, Environments, Messages, Services) frameworks.  
It focuses on how children engage with digital games—capturing not just actions, but emotions, context, and design implications.

---

 Features
- Structured observation fields for AEIOU + POEMS categories  
- Clean, playful UI built with React + TypeScript + Vite  
- Ready for field researchers and design educators  
- Export-ready layout for reports and visual summaries  

---

 Tech Stack
- React + TypeScript + Vite
- Tailwind CSS for styling
- Lucide Icons and shadcn/ui for consistent UI
- Context API for theme control
